# Casa-Inteligente-Arduino
Maqueta de casa inteligente con Arduino, sensores y control por Bluetooth
## Tecnologías Utilizadas
-Arduino UNO
-C++
-Bluetooth (control desde app móvil)
-Sensor ultrasónico HC-SR04
-Servo motor y motor paso a paso

##Funcionalidad
-Control de iluminación automatizado
-Apertura/Cierre de puerta principal vía Bluetooth desde aplicación móvil
-Control de garaje mediante sensor de proximidad
-Lógica de control desarrollada con programación modular en C++
